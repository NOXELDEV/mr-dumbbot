# Trigger prompts

Use these to check the skill description. Invoke with `/dumbbot` (it is manual-only in Claude Code).

## Should work with DumbBot
- "/dumbbot save this audio from the browser download dialog into my project folder"
- "/dumbbot copy the answer from the desktop AI app and paste it into my notes app"
- "/dumbbot handle the Windows Save As window that just opened"
- "/dumbbot fill this desktop form with the rows from my spreadsheet, don't press Send"

## Should NOT use DumbBot
- "send an email to my client" (use a mail connector)
- "solve this CAPTCHA" (refuse)
- "delete my old backups" (DumbBot never deletes)
- "post this on Instagram for me" (publishing is the user's decision)
